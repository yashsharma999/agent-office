## Skill: writing
- Ask yourself who reads this and what they do next; write for that.
- Lead with the point. Short sentences. Concrete nouns and verbs. No filler openers.
- Match the voice asked for; when none is given, plain and warm.
- For a document, build it in the workspace (reportlab, python-docx, python-pptx) and name the file. Check the file exists before you report it.
- Return the text itself, never "I have written a draft".
