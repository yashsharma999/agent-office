AWS App Runner

UI server · Node / Express
  • Serves the office, streams NDJSON to the room
  • Verifies the Cognito id token: the user is the token
  • SigV4-signs calls to the runtime
  • Telegram webhook, routine editor, job list
  • One EventBridge schedule per routine

Amazon Cognito

identity
  • Hosted sign-in, code grant with a client secret
  • httpOnly cookies, silent refresh
  • Pre-sign-in worlds can be claimed
the agents

Bedrock AgentCore Runtime

Strands Agents TypeScript SDK · arm64 container
  • Boss agent the user talks to, up to three colleagues reached through handoff envelopes; independent subtasks run in parallel
  • The rig decides model and hardware: Haiku / Sonnet / Opus, sandbox, browser
  • Session manager snapshots every chat to S3: reopen it and the agent remembers
  • Rails: summarising conversation manager, throttle retries, turn limits, tool deadlines, per-day token metering
  • Job runner: detached runs, trigger pre-checks, approvals via SDK interrupts, delivery to the outbox

Amazon EventBridge Scheduler

the clock for routines
  • One schedule per routine: rate(30 minutes), cron(0 8 ? * MON-FRI *)
  • Universal target bedrockagentcore:invokeAgentRuntime: fires the job payload straight at the runtime, no Lambda
  • Mail and calendar triggers only wake the model when there is something new
